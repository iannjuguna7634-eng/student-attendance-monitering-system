# Student Attendance Monitoring System
A working GitHub Pages compatible demonstration website.

## Features
- Home page and demo login
- Dashboard with live statistics
- Add, edit, delete and search students
- Attendance by date with Present / Absent / Late
- Attendance reports and rates
- Printable reports
- JSON data export
- Reset demo data
- Responsive layout
- Browser localStorage (no PHP/MySQL needed for this demo)

## Demo login
Username: `admin`
Password: `1234`

## Run
Open `index.html` in a browser.

## GitHub Pages
Upload the whole folder to a repository, keeping the `css` and `js` folders. In GitHub, open Settings -> Pages, select the main branch and root folder, then save.
